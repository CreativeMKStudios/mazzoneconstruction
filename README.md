# Mazzone Construction

Static site for Mazzone Construction, stonemasons and builders in Kettering. Built with Astro.

```bash
npm install
npm run dev
npm run build
```

The production address is set to `https://mazzonelimited.com`. Point that domain at the `dist` folder after `npm run build`.

Facts on the site come from the Google Business profile, the old Mazzone website, and published Google reviews. Review spelling is unchanged. The site does not invent project addresses or accreditations.
